## 2026-07-16 - BeforeAfterGallery Performance Optimization
**Learning:** Frequent interactive events like mousemove and touchmove inside a custom image comparison slider component can trigger layout thrashing and high main-thread CPU overhead if they call `getBoundingClientRect()` inside the interaction handler. Furthermore, triggering React state updates synchronously on every single input event triggers excessive re-renders.
**Action:** Cache the container element's `DOMRect` dimensions in a React `useRef` at the beginning of the drag gesture (`onMouseDown` or `onTouchStart`), so layout measurements are computed exactly once per gesture rather than 60+ times per second. Throttle visual updates using `requestAnimationFrame` (rAF) and save interaction event listener references inside `useRef` variables to guarantee reliable cleanup in `useEffect`'s return statement even if the component unmounts mid-drag.
