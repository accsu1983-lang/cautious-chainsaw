## 2026-03-13 - Declarative High-Frequency Drag Events in React
**Learning:** Attaching global event listeners using imperative selector lookups (e.g. `querySelector` inside `useEffect`) is highly fragile, breaks React encapsulation, and causes redundant listener attachment during component updates or slide changes. Using declarative synthetic event handlers on target JSX elements to initiate drag state, while scoping move/end listeners dynamically on the document level, keeps event listeners clean and highly stable.
**Action:** Always prefer native React synthetic handlers (`onMouseDown`, `onTouchStart`) for starting interactions. Cache layout measurements inside state-free mutable `useRef` containers to prevent browser layout thrashing during subsequent mouse/touch move events.
