## 2026-03-13 - Throttling High-Frequency Window Scroll Events with requestAnimationFrame
**Learning:** High-frequency event listeners (like scroll, resize, and mousemove) fire constantly on the main thread and can trigger frequent, expensive state updates in React. In this codebase, three separate widgets (BackToTop, CTABar, and WhatsAppWidget) listened to scroll event streams to dynamically show/hide themselves based on `window.scrollY` thresholds. Throttling these listeners using `window.requestAnimationFrame` ensures state updates are debounced and only execution-aligned with the browser's paint pipeline, removing heavy frame rate drops during scrolling.
**Action:** Always throttle scroll/resize listeners using lightweight `requestAnimationFrame` ticking, and declare `{ passive: true }` so the browser can optimize the scroll pathway without waiting for JS execution.
