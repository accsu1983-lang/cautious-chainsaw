## 2025-08-13 - [Supabase Middleware Session Verification Skip for Anonymous Users]
**Learning:** Checking Supabase auth session (`supabase.auth.getUser()`) on every single middleware match can significantly degrade Time to First Byte (TTFB) for anonymous visitors. Since the middleware runs on every non-static/non-media asset request, instantiating the client and making an API call/session validation for every public page load is a major performance bottleneck.
**Action:** Detect if the request path is a non-protected path (not starting with `/protected`, `/admin`, or `/api/admin`) and check if any Supabase-specific cookies (e.g., starting with `sb-`) exist. If the path is public and no Supabase session cookies are present, skip the Supabase client instantiation and session check entirely, resulting in immediate early returns in Next.js middleware and vastly faster page load times.
