## 2026-07-23 - Throttling High-Frequency Window Scroll Events
**Learning:** High-frequency event listeners like `window.onscroll` execute continuously during scrolls, putting heavy pressure on the main thread. Without throttling, this leads to unnecessary react-re-renders, reflows, and layout thrashing, hurting scrolling frame rates (especially on mobile devices). Throttling with a lightweight 100ms interval and marking listeners as `{ passive: true }` instructs the browser that the scroll handler will not call `preventDefault()`, allowing for immediate, buttery-smooth scrolling updates.
**Action:** Always throttle high-frequency window events (scroll, resize, mousemove, touchmove) using a lightweight custom `throttle` helper, persist the throttled callbacks across renders with `useMemo` (or `useCallback`), add `{ passive: true }` when appropriate, and ensure `.cancel()` is called on unmount inside `useEffect` cleanup to avoid memory leaks.
