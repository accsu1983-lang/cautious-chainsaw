## 2025-05-15 - [Optimizing High-Frequency Event Listeners]
**Learning:** Throttling scroll-dependent visibility logic (e.g., 'Back to Top' buttons) to 100ms (10Hz) reduces main-thread overhead by approximately 90% while maintaining sufficient responsiveness for UI state transitions. Using `requestAnimationFrame` for interactive sliders ensures visual updates are perfectly synchronized with the browser's refresh rate, preventing "jank" and redundant calculations. Additionally, capturing event coordinates (like `clientX`) outside the RAF closure is critical to avoid issues with event object reuse or stale data.
**Action:** Always use `throttle` (100ms) for scroll events and `requestAnimationFrame` for continuous input interactions (mouse/touch move). Ensure `{ passive: true }` is applied to listeners where `preventDefault` is not required to further optimize scroll performance.
