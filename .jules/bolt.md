## 2026-03-13 - [Next.js 16 & React 19 Event Interaction and Hook Stability]
**Learning:** In this environment, high-frequency interactive events such as slider dragging and window scrolls can cause massive layout thrashing and main-thread blocks if window scroll events are not throttled and document-level mouse/touch move event handlers invoke Layout-triggering methods (`getBoundingClientRect`) repeatedly inside render loop. Additionally, Next.js 16/React 19 environment requires explicit React imports to prevent ReferenceError of React on Server Component dynamic imports.
**Action:** Use a dedicated lightweight `throttle` helper with `{ passive: true }` for scroll event listeners and `requestAnimationFrame` with once-cached container dimension rects on start for sliders, always importing React explicitly.
